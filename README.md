# เลขาเป็ด (demolekaped)

ต้นแบบ AI เลขาบน LINE + Supabase สำหรับนำเสนอ หน้าเดียว (`index.html`) มี 4 ส่วน:

- **โครงสร้างระบบ 3D**: ภาพ 3 มิติแสดงเส้นทางข้อมูล
- **ลองใช้งาน**: แชตจำลองในมุม CEO / หัวหน้า / พนักงาน (ใช้กฎตายตัว ยังไม่ต่อ AI จริง ข้อมูลเป็นตัวอย่างสมมติ)
- **แผนการสร้าง**: ส่วนประกอบ ฐานข้อมูล และแผนงาน
- **ทำได้จริงไหม**: ฟีเจอร์ทีละข้อ ข้อเสีย และค่าใช้จ่าย

เปิดดูได้โดยเปิด `index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages ของ repo นี้
