# IPED · ระบบออกแบบ (ย่อ)

ใช้ร่วมกันระหว่างการ์ด Flex ในแชต (`supabase/functions/_shared/flex.ts`) และหน้า LIFF (`liff/shared/app.css`, `liff/calendar/index.html`)

## ตัวตน
- มาสคอต: เป็ดเหลืองใส่เนกไทกรมท่า ถือคลิปบอร์ดที่มีเครื่องหมายถูก (ออกแบบใหม่ทั้งหมด ไม่อิงแบรนด์อื่น)
- `lekaped-mark.svg` / `lekaped-mark-128.png` เครื่องหมายวงกลม (หัวเป็ด + ปกเสื้อ) ใช้ที่หัวการ์ดและหัวหน้า LIFF ขนาด 34–40px
- `lekaped-mascot.svg` / `-240.png` / `-480.png` ตัวเต็ม ใช้ในหน้าว่าง หน้ากำลังโหลด และสถานะ
- `lekaped-hero-1040x520.png` ภาพแบนเนอร์ 2:1 ของการ์ดต้อนรับ
- `lekaped-profile-640.png` รูปโปรไฟล์ LINE OA (LINE ตัดเป็นวงกลม เป็ดอยู่กลางภาพแล้ว)
- ส่งออก PNG ใหม่หลังแก้ SVG: `node tools/flex-preview/export-assets.mjs`
- ที่อยู่บนเว็บ: `https://thanachai-no-hub.github.io/demolekaped/liff/assets/<file>` (เปลี่ยนได้ด้วย env `LEKAPED_ASSET_BASE`)

## ตัวอักษร (Flex keyword → px โดยประมาณ)
- บรรทัดคำตอบ (hero): `xl` 22px ตัวหนา (ยาวเกิน 16 ตัว → `lg` 19px) สีตามสถานะ
- ชื่อการ์ด: `sm` 14px หนา · "IPED" `xxs` 11px หนา
- เนื้อหา: `sm` 14px · บรรทัดรอง/คีย์: `xs` 13px สีรอง · ป้ายสถานะ: `xxs` 11px หนา
- LIFF: IBM Plex Sans Thai 15px · หัวหน้า 18px · ปุ่ม/แท็บสูงอย่างน้อย 44px

## ระยะ
- ฟองการ์ด `mega` (300px) · ขอบใน 16px · ระยะระหว่างแถว `md` (8px) · หัวข้อย่อยเว้นบน `lg`
- มุมโค้ง: กล่องย่อย 10px · ป้าย 99px · ปุ่ม LINE ตามค่าเริ่มต้น

## กติกาการ์ด
1. 1 การ์ด = 1 เรื่อง · หัว = เป็ด + ชื่อการ์ดสั้นๆ
2. สิ่งแรกในเนื้อหา = คำตอบ/สถานะตัวใหญ่ (`hero`) + บรรทัดรอง (`sub`) เช่น "เลยกำหนด 2 งาน", "รอคุณอนุมัติ"
3. ต่อด้วยไม่เกิน ~5 แถวสั้น ภาษาคน · วันที่แบบ "พรุ่งนี้ 17:00" / "เลยกำหนด 2 วัน"
4. สถานะ = ป้ายสีพร้อมไอคอน (⏰ เลยกำหนด · ⚠ ติดปัญหา · ⏳ รอ · ▶ กำลังทำ · ✓ เสร็จ)
5. ความคืบหน้า = แถบหนา 8px + % ด้านขวา
6. ปุ่มหลักสีเขียว 1 ปุ่ม + ปุ่มรองแบบลิงก์ไม่เกิน 2 (เทา = ยกเลิก/ปฏิเสธ) · เกิน 3 ปุ่มย้ายไป quick reply
7. รายการยาว: แสดง 3–4 อันแรก + "และอีก N งาน" + ลิงก์ "ดูทั้งหมด ›" ไปหน้า LIFF
8. altText = "ชื่อการ์ด · คำตอบ" (เห็นในการแจ้งเตือน)
9. ข้อจำกัด LINE: bubble ≤ 30KB · ปุ่ม ≤ 3 · label ≤ 20 ตัว · altText ≤ 400 · รูปต้อง https → ตรวจด้วย `node tools/flex-preview/validate.mjs`
